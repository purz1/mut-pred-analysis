# Cell-Level Feature Parquet Files

Generated by:
- `v3_extract_cell_level_bm_features_for_mutation_prediction.py` → BM parquet
- `v3_extract_cell_level_pb_features_for_mutation_prediction.py` → PB parquet

Each row represents one detected cell. Samples are identified by `(database_id, album_id)`.

---

## Shared columns (BM and PB)

### Identifiers

| Column | Type | Description |
|---|---|---|
| `database_id` | str | MGG database year (e.g. `"2023"`) |
| `album_id` | str | Sample/patient identifier |
| `cell_id` | int | Original row index of the cell in the HDF5 file; unique within a sample |

### Cell type

| Column | Type | Description |
|---|---|---|
| `class_label` | str | Cell type name; see cell type tables below |

### Shape features

All shape features are computed on the segmented cell mask. Areas are in relative units (proportion of image area).

| Column | Description |
|---|---|
| `nucleus_area` | Area of the nucleus |
| `nucleus_solidity` | Nucleus area / convex hull area; lower = more irregular or lobulated |
| `nucleus_eccentricity` | Elongation of nucleus; 0 = circle, 1 = line |
| `nucleus_compactness` | Nucleus perimeter² / area; higher = rougher or more irregular boundary |
| `entire_area` | Total cell area (nucleus + cytoplasm) |
| `entire_solidity` | Solidity of the whole cell |
| `entire_eccentricity` | Eccentricity of the whole cell |
| `entire_compactness` | Compactness of the whole cell |
| `entire_N:C-ratio` | Nuclear-to-cytoplasmic ratio: `(entire_area - cytoplasm_area) / entire_area`; higher = larger nucleus relative to cell |

### Shared dysplasia flags

Binary flags derived from model output probabilities using fixed cutoffs. `True` = dysplasia detected.
Flags are computed for all cells regardless of cell type, but only make biological sense for the cell types listed.

| Column | Cutoff | Biologically relevant for |
|---|---|---|
| `vacuolated` | > 0.50 | Blasts, Promyelocytes, Myelocytes (BM); Erythroblasts (BM) |
| `mds_asynchrony` | > 0.60 | Erythroblasts |
| `mds_dysmorphic` | > 0.50 | Erythroblasts |
| `mds_multinucleated` | > 0.50 | Erythroblasts |
| `mitotic` | > 0.50 | All living cells |
| `apl_auer` | > 0.75 | Blasts, Promyelocytes, Myelocytes |
| `apl_bilobed` | > 0.65 | Blasts, Promyelocytes, Myelocytes |
| `apl_hypergranulated` | > 0.50 | Blasts, Promyelocytes, Myelocytes |

### Quality flags

| Column | Type | Description |
|---|---|---|
| `low_quality` | float [0–1] | Per-cell quality score from the main classifier. The aggregation functions use `low_quality < 0.5` as a gate for dysplasia numerators and denominators, matching the HDF5 pipeline. You can also use this column directly to filter cells. |
| `quality_model_filtered` | bool | `True` if the cell would be excluded from the statistics pipeline. For BM: excludes cells failing per-cell-type ONNX quality models, Insufficient megakaryocytes (size filter), or the granulocyte quality filter. For PB: excludes cells failing the granulocyte quality filter (no ONNX models for PB). Use `~quality_model_filtered` to replicate the original sample-level statistics cell population. |

## BM-only columns

### BM cell types (`class_label`)

`Basophils`, `Blasts`, `Eosinophils_immature`, `Eosinophils`, `Erythroblasts`, `Lymphocytes`, `Macrophages`, `Megakaryocytes`, `Metamyelocytes`, `Monocytes`, `Myelocytes`, `Neutrophils`, `Plasma_cells`, `Proerythroblasts`, `Promonocytes`, `Promyelocytes`

### BM-specific dysplasia flags

| Column | Cutoff | Biologically relevant for |
|---|---|---|
| `mgk_multinucleated` | > 0.50 | Megakaryocytes |
| `mgk_hypolobated` | > 0.60 | Megakaryocytes |

---

## PB-only columns

### PB cell types (`class_label`)

`Band_neutrophils`, `Basophils`, `Blasts`, `Eosinophils`, `Erythroblasts`, `Giant_platelets`, `Lymphocytes`, `Metamyelocytes`, `Monocytes`, `Myelocytes`, `Plasma_cells`, `Platelet_aggregations`, `Segmented_neutrophils`

### PB-specific dysplasia flags

| Column | Cutoff | Biologically relevant for |
|---|---|---|
| `macropolycyte` | > 0.50 | Band_neutrophils, Segmented_neutrophils |

### Neutrophil morphology flags

Two independent 3-way classifiers applied to all cells; biologically meaningful only for Band_neutrophils (class 1) and Segmented_neutrophils (class 13). Exactly one flag per classifier will be `True` per cell.

**Granulation** (cytoplasmic granule content):

| Column | Description |
|---|---|
| `neut_gran_normal` | Normal granulation |
| `neut_gran_hypo` | Hypogranulation — reduced granules; dysplastic finding in MDS |
| `neut_gran_hyper` | Hypergranulation — excessive granules |

**Segmentation** (nuclear lobe count):

| Column | Description |
|---|---|
| `neut_segm_normal` | Normal segmentation |
| `neut_segm_hypo` | Hyposegmentation — too few lobes; Pelger-Huet-like anomaly |
| `neut_segm_hyper` | Hypersegmentation — too many lobes; seen in B12/folate deficiency |

## Filtering notes

The following cells are always excluded from the output (not present in the parquet):
- Artefacts (BM class 0)
- Unknowns (BM class -1)
- Background/RBCs (PB class 14)

Cells with `quality_model_filtered = True` are included in the parquet but flagged. Filter them out with:
```python
df = df[~df["quality_model_filtered"]]
```

## Aggregating to sample level

Use `v3_aggregate_from_cell_level.py` to go from cell-level parquet to sample-level features matching the original HDF5 pipeline output.

```python
from v3_aggregate_from_cell_level import aggregate_bm_dataset, aggregate_pb_dataset

cell_df = pd.read_parquet("cell_level_features_*.parquet")
sample_df = aggregate_bm_dataset(cell_df, filter_type="all")  # (database_id, album_id) index
```

The `filter_type` parameter controls which feature group is computed:

| `filter_type` | Cell filter applied | Output |
|---|---|---|
| `"cell_differential"` | All cells | Cell type proportions, lineage proportions, mitotic/vacuolated proportions (+ neutrophil gran/segm for PB) |
| `"dysplasia"` | `low_quality < 0.5` | APL/MDS/MGK/overall dysplasia proportions |
| `"cell_statistics"` | `~quality_model_filtered` | Per-cell-type shape feature medians and 95% ranges |
| `"all"` | All of the above | All columns from all three feature groups concatenated |

## Filtering by cell_id before aggregation

If you have another DataFrame with `(database_id, album_id, cell_id)` identifying a subset of cells (e.g. cells selected by a model), merge it into the parquet before aggregating:

```python
# other_df has columns: database_id, album_id, cell_id
keys = other_df[["database_id", "album_id", "cell_id"]].copy()
keys["database_id"] = keys["database_id"].astype(str)
keys["album_id"] = keys["album_id"].astype(str)

cell_df_filtered = cell_df.merge(keys, on=["database_id", "album_id", "cell_id"], how="inner")
sample_df = aggregate_bm_dataset(cell_df_filtered, filter_type="all")
```

The aggregation then runs only on the selected cells, so all proportions and statistics reflect that subset.
